# 123camera — 개인정보처리방침 (Privacy Policy)

안드로이드 앱 **123camera** (`com.joahn.camera123`)의 개인정보처리방침을 공개하는 저장소입니다.
앱 소스코드는 포함되어 있지 않습니다.

## 공개 주소

```
https://jaohn1110.github.io/123camera-privacy/
```

이 주소를 다음 두 곳에 사용합니다.

1. Google Play Console → 앱 콘텐츠 → **개인정보처리방침 URL**
2. 앱 내 설정 화면 → '개인정보처리방침' 항목 (외부 브라우저로 열기)

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 개인정보처리방침 본문 (한국어 + English) |
| `.nojekyll` | GitHub Pages의 Jekyll 처리를 끔 (파일을 그대로 서빙) |
| `README.md` | 이 문서 |

## 수정하는 방법

1. `index.html`을 열어 내용을 고칩니다.
2. 상단의 **시행일 / Effective**과 **버전** 표기를 함께 올립니다.
3. 커밋 후 push하면 1~2분 안에 웹페이지에 자동 반영됩니다.

> 주소는 그대로 유지되므로, 내용을 바꿔도 Play Console이나 앱 코드를 다시 고칠 필요가 없습니다.
